Engineering Evaluation Platform (EEP)

Reproducible evaluation infrastructure for AI-assisted software engineering. This page is a static landing page published from this repository's docs/ folder via GitHub Pages — see the source repository for everything else.

No real, live-LLM benchmark result has been published yet. Everything linked below is either a test fixture, a free mechanism-verification run, or an explicitly labeled synthetic demo — see each artifact's own limitations section before drawing any conclusion from it.
  • Sample dashboard — a real, self-contained rendering of the dashboard produced by npm run demo:generate, against two literal synthetic runs. Demonstrates the dashboard renderer, not a benchmark result.
  • BENCHMARK.md — what the benchmark measures, task categories, and experiment design. Served here as a raw file (this site has no Markdown renderer); best read on GitHub.
  • REPRODUCING.md — how to run the benchmark yourself, including a free npm run reproduce:smoke path that needs no credentials, and how to compare your results against someone else's.
